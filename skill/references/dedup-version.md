# 重复件与版本规则

## 判断层级

- 完全重复：SHA-256 一致。保留全部原路径记录，只选一份主文件进入事实分析。
- 疑似重复图片：视觉内容相同，但尺寸、裁剪、压缩、标注或元数据不同。分别保留，标记候选组，人工确认。
- 不同格式副本：Word/PDF、原表/截图等内容高度相近。不是完全重复，分别保留并建立关联。
- 独立版本：初稿、修订稿、签署版、盖章版、补充版。不是重复件，必须分别保留并记录版本关系。
- 载体副本：原件、扫描件、照片、截图、转发件。分别保留，注明载体和来源链路。

## 主分析文件

每个重复组仅指定一个“主要分析文件”，优先级通常为：可核验原件/签署版 → 清晰扫描件 → 完整电子件 → 照片/截图 → 转发压缩件。优先级不是真实性结论；存在签署、内容或元数据差异时不得自动选定。

重复文件仍全部写入内部技术 JSON，记录重复组编号、主文件材料编号和所有原路径。面向律师的 `材料统计与目录.txt` 不展示这些技术字段；时间轴引用主要分析文件。

## 版本关系

使用稳定组号 `DUP-001` 与版本组号 `VER-001`。记录：材料编号、版本标签、形成时间、内容差异、签章状态、与前版关系、是否主要分析文件。

`final`、`最终版`、`最新版` 只作为原文件名线索，不能证明其确为最终版本。

## 近似判断限制

感知哈希、文本相似度和文件名相似度仅用于生成候选，不得据此删除、覆盖或自动淘汰材料。图片裁剪可能丢失关键上下文，PDF 与 Word 可能存在签章差异，必须保留并提示复核。

## 禁止事项

不得删除重复件；不得用主文件覆盖副本；不得把不同版本合并成一个新文件；不得隐藏版本间金额、日期、条款或签章差异。
