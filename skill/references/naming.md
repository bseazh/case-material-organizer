# 命名规则

## 案件根文件夹

整个整理结果文件夹固定使用：

```text
{序号}-{原告简称}VS{被告简称}-{案由}
```

例如：`1-张三VS李四-买卖合同纠纷`。

- 序号使用从 `1` 开始的正整数；
- `VS` 必须大写；
- 原告简称、被告简称和案由不得为空，不得包含 `-` 或文件系统禁用字符；
- 四项信息必须在归档预览中让用户确认，不得根据材料擅自补造；
- 执行归档时，实际根文件夹名称必须与确认结果完全一致。

## 标准格式

```text
{日期}-{简明材料名称}.{原扩展名}
```

日期优先使用材料内容中的日期，其次使用文件名日期，最后才使用文件系统日期。文件名日期不能证明内容日期时，在内部方案中标记日期来源，律师报告统一写“待确认”。

## 日期格式

```text
260715-民事上诉状.docx
240312-林晚晴加班沟通.png
240308-240310-盘点加班记录.xlsx
2403-林晚晴工资条.jpg
时间待核-主管沟通记录.txt
```

规则：年月日用 `YYMMDD`；范围用 `YYMMDD-YYMMDD`；只有月份用 `YYMM`；未知日期使用 `时间待核`。不得把“违法、恶意、必然胜诉”等法律结论写进文件名。

## 简明材料名称

格式建议：`主体/群体 + 材料类型或事实主题`，不超过 32 个汉字；保留原扩展名。例：`240722-孙浩现场事故记录.docx`。

## 重名和版本

同名追加 `-02`、`-03`；原文件名另存于索引，不丢失。版本词 `初稿`、`修订稿`、`签署版`、`转发版` 必须保留，不能用 `final` 覆盖版本判断。

## 关联逐字稿

优先命名：

```text
240403-主管改班说明.wav
240403-主管改班说明-逐字稿.txt
```

逐字稿作为独立文件归档，并在内部方案中记录关联媒体原文件。
