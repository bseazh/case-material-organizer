# 音视频与逐字稿规则

## 不处理媒体本体

音频和视频不播放、不转写、不做语音识别、不从时长或文件名推断事实。原媒体仍计入“材料清单”并复制归档。

## 可接受逐字稿

TXT、MD、DOCX、PDF 均可作为逐字稿；扫描 PDF 需要 OCR。逐字稿必须独立保存，不能只存在于聊天消息中。

## 自动匹配优先级

1. 基础文件名完全相同，仅扩展名不同；
2. 基础文件名相同并增加 `-逐字稿`、`_逐字稿` 或 `（逐字稿）`；
3. 逐字稿正文明确写明对应媒体文件名；
4. 其他情况只能列为候选，交给用户确认。

## 状态枚举

`已匹配-纳入文本分析`、`待用户确认匹配`、`缺少逐字稿-未解析`、`逐字稿解析失败`、`不适用`。

已匹配逐字稿只作为逐字稿文本来源，不代表录音真实性或内容已被确认。时间轴中应标记来源为“逐字稿材料记载”，并保留待核事项。
