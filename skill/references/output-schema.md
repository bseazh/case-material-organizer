# 输出结构与字段

## 结果目录

```text
{原文件夹名}_整理结果/
├── 001 主体信息/
├── 002 基础资料/
│   └── index.md
├── 003 委托材料/
├── 004 类案及法律检索/
├── 005 法律文书/
├── 案件材料汇总.xlsx
├── 归档结果目录.md
└── index.txt
```

原始文件夹不放入结果目录，不改变其内容。分类结果默认是副本。

## Excel 工作表顺序

1. `案件链路总览`：对整个案件材料链路的摘要，不是单文件摘要。
2. `文件清单`：材料编号、原始文件名、原始路径、标准文件名、归档路径、扩展名、哈希、状态。
3. `主体信息`：主体、别名、角色、出现材料、待确认事项。
4. `音视频核对`：媒体文件、逐字稿、匹配状态、是否纳入事实提取。
5. `时间轴`：事件编号、事件发生时间、材料形成时间、时间精度、地点/渠道、涉及主体、事件描述、主要材料编号、全部关联材料编号、原文定位、归档路径、记载性质、冲突/待核。
6. `冲突与待核`：问题、涉及材料、影响、下一步补证建议。

## 链路总览要求

总览至少包含：案件名称、材料范围、涉及主体、时间跨度、核心争议链路、关键金额或数量（如有）、证据相互印证关系、主要冲突、资料缺口、未解析媒体。不得把单个文件摘要拼接成结论；必须基于合并后的事件，说明“起因—过程—争议—现状—缺口”的整体链路，并引用关键事件编号和材料编号。

## index.txt

第一部分写案件链路摘要，与 Excel 的“案件链路总览”保持一致；第二部分写总计、可解析数、OCR数、媒体数、已匹配逐字稿数、待补逐字稿数、重复数、失败数；第三部分逐项写原路径、原文件名、标准文件名、归档路径、材料编号和状态。

## 002/index.md

按材料日期升序；日期未知置于末尾。至少包含：日期、材料名称、相对路径、材料编号、对应时间轴事项。

## 归档结果目录.md

必须根据已执行方案生成，包含五个一级目录的实际目录树、各类数量、原文件名到实际文件名映射、重复件/媒体/失败统计和完成后的 A/B/C 选项。AI 交付时必须把目录树和选项直接展示在对话中，不能只提供该文件路径。
