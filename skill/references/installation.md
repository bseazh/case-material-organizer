# 安装、更新与网络规则

本文件用于 Skill 已安装后的环境修复、更新或重装。首次下载前应读取仓库根目录 `INSTALL.md`。

## 固定顺序

1. 首次安装或版本变化时，只审查一次 `package.json` 与 `bin/cli.js`。
2. 执行 `npx github:` 时，Agent 工具等待时间至少为 300 秒。
3. 接近等待上限后出现 `137`、`SIGTERM` 或超时，先检查目标文件是否存在；未完成时只重试一次。
4. 先运行 `doctor`，只补它报告缺少的能力。
5. Python 包先用默认 PyPI；默认源失败后才根据错误和网络环境决定是否换镜像。
6. 安装结束后用命令退出码和一次 `doctor` 验收，不截断关键输出，不重复执行无必要的 `pip list`。

## 网络判断

- 默认 PyPI 偶发 TLS、连接重置或超时：默认源重试一次。
- 镜像出现 `502`、`403` 或代理错误：停止使用镜像，回到默认源。
- 默认源持续不可达且无强制代理：询问用户后再使用镜像。
- 不关闭 TLS 校验，不添加 `--trusted-host` 规避证书。

## 更新与重装

若目标 Skill 已存在，不直接覆盖。先说明当前版本和目标版本，再由用户选择备份后更新或保留现状。不得为了处理一次超时而删除已安装目录。

## 可选大组件

Poppler、Tesseract 中文语言包和浏览器组件只在相应任务需要时安装。缺失时标记对应文件或导出格式暂不可用，其他材料继续处理。
