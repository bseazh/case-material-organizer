# 给 Agent 的说明

本仓库是面向**中国大陆成文法（PRC statutory law）**的法律推理技能库（Agent Skills）。权威内容在中文源文件，不在 `English/`。

---

## 法域与角色

- **默认法域**：中国大陆成文法。案例原则上不具有普遍约束力（最高人民法院指导性案例除外）；在刑法定罪量刑、税法课税要件等场景，类比推理受严格限制甚至禁止。
- **你的角色**：辅助分析工具。输出一律视为**供执业法律专业人员审阅的草稿**，不构成法律意见、法律结论，也不能替代律师。
- **其他法域**（港澳台、普通法等）：须先声明法域前提已变更，并经用户确认后再调整分析框架；不得默认沿用本库的中国大陆前提。

---

## 如何选择技能

1. 先读目标技能 `SKILL.md` 的 `description` / 触发条件与能力边界，再决定是否调用。
2. **范围较窄、目标单一**的任务（检索一条法条、提取一组要素、完成一次演绎、评估一段论证强度等）→ **优先使用对应原子技能**；需要多步时，按任务链路显式串联多个原子技能。
3. **端到端复杂任务**（生成完整裁判文书、法律判决预测等）→ **使用复合技能**（`judgment-document-generation`、`legal-judgment-prediction`）。复合技能是编排层，按固定主线调度原子技能；除非用户明确要求逐步手工调用，否则不要绕过编排层自行拼凑全流程。
4. 拿不准时：选**边界更窄、与用户表述最贴合**的技能；同一时刻以**一个主导技能**为准，避免并行加载互相冲突的指令集。

复合技能的典型调度主线（供对照，具体以该技能 `SKILL.md` 为准）：

```text
事实要素提取 → 概念理解 → 争议识别 → 法条检索 → 案例检索 → 演绎推理 → 格式适用 → 术语规范
```

---

## 硬规则：法律依据与检索

- **绝不编造**法条编号、条文内容、司法解释、案例案号、裁判要旨、效力状态或任何「看似权威」的引用。
- 检索类技能（如 `legal-article-retrieval`、`case-retrieval`、`legal-norm-validity-check`）只定义检索方法论，**不绑定**特定数据库。环境中已接入 MCP / 检索工具时，须**实际调用并依据返回结果**再引用。
- **无法检索、工具不可用、或结果不足以支撑结论时**：
  1. 明确告知用户：未检索到 / 工具不可用 / 依据不足；
  2. 对拟引用但尚未核验的依据标注 `[待检索]` 或 `[待查]`；
  3. 可以给出分析框架、争点整理与下一步检索建议；
  4. **不得**用模型记忆冒充现行有效法源，也不得把未核验内容写成确定结论。

## 指令冲突时的优先级

当用户要求、本文件、技能正文、其他文档或模型先验互相冲突时，按下列顺序服从（高 → 低）：

| 优先级 | 来源 | 说明 |
|:--|:--|:--|
| 1 | **安全与真实性硬约束** | 不编造法律依据；输出仅为辅助草稿；遵守用户明确的合规 / 保密要求 |
| 2 | **用户对本轮任务的明确指令** | 含法域、是否允许假设、输出格式、不得使用的材料等 |
| 3 | **本文件 `AGENTS.md`** | 法域默认、选技原则、检索失败处理等仓库级规则 |
| 4 | **当前激活技能的中文 `SKILL.md`** | 该技能的步骤、边界与 I/O 格式 |
| 5 | **仓库其他中文文档** | `README.md`、`CONTRIBUTING.md`、`MCP-PKULAW.md` 及技能目录内说明 |
| 6 | **`English/` 英译与模型默认先验** | 仅供对照；不得覆盖中文源或更高优先级规则 |

## 维护本仓库时（编码 Agent）

### 你应当做什么

- 阅读、修改、新增技能时，只处理仓库根目录下的中文源：
  - `skills/`（每个技能的 `SKILL.md` 等）
  - 根目录文档：`README.md`、`CONTRIBUTING.md`、`MCP-PKULAW.md` 等
- 以中文 `SKILL.md` 为唯一事实来源；贡献与评审也以中文版为准。

### 你不需要做什么

- **不要**进入或依赖 `English/`（英译平行树）来理解或修改技能逻辑。
- `English/` 面向人类读者与展示，**不是**日常编码的工作区。

### 目录分工（一句话）

| 路径 | 角色 |
|------|------|
| `skills/` 等中文源 | 唯一工作区 / 权威资源 |
| `English/` | 英译镜像，见该目录内 `AGENTS.md` |

若任务是「翻译」，再按 `English/AGENTS.md` 执行；默认任务一律只动中文源。
