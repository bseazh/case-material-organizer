# LawyerBuddy 使用指南

本指南面向律师和法律助理，说明如何在 Workbuddy 中导入 LawyerBuddy，以及如何开始材料整理、案件总结、起诉状起草和合同起草。所有生成内容均为工作草稿，须由律师核对。

## 在 Workbuddy 导入

1. 在 LawyerBuddy 仓库根目录运行 `npm run pack:workbuddy`，生成 `dist/lawyerbuddy-workbuddy-版本号/` 上传文件夹和同名 ZIP；也可以从 [GitHub Releases](https://github.com/bseazh/lawyerbuddy/releases) 下载 ZIP 并解压。
2. 在 Workbuddy 的 Skill 管理页面选择导入文件夹，选中生成的 `dist/lawyerbuddy-workbuddy-版本号/`。如果使用 ZIP，则直接上传 ZIP 或选择解压后能直接看到 `SKILL.md` 的那一层；不要选择外层仓库目录。
3. 确认选中的文件夹第一层直接包含 `SKILL.md`，且该文件有 YAML 格式的 `name` 和 `description`。导入成功后，在对话中调用 `@lawyerbuddy`。若平台不支持 `@`，直接说“请使用 LawyerBuddy Skill”。

每个新会话可以重新提供案件材料文件夹的绝对路径；不要假设 Agent 能访问未添加到当前工作区的本地文件。

## 材料整理与案件初稿

把案件文件夹添加到 Workbuddy 工作区后，复制下面的提示词并替换路径：

```text
@lawyerbuddy

请整理这个案件材料文件夹：
/填写案件材料文件夹的绝对路径

先检查材料和录音逐字稿，再根据材料提出案由候选。请展示拟定的案件名称、目录树和文件改名预览，等我确认后再复制归档。原始材料保持不变。
默认生成快速案件初稿和可视化时间轴；未核实内容标为“待确认”，不要把材料中的单方陈述写成已确认事实。
```

Workbuddy 展示归档目录树和改名预览后，先核对案由、当事人简称、目录和文件名称，再明确回复是否执行。发现录音缺少逐字稿时，先按 Agent 提供的清单补充或确认逐字稿，再继续案件分析。

## 文书起草

### 从已整理案件开始

如果已有案件梳理报告和材料目录，提供案件目录路径，并说明要起草的文书、委托方立场和程序阶段：

```text
@lawyerbuddy-complaint-draft

请使用 LawyerBuddy 起草民事起诉状。

案件目录：
/填写已整理案件文件夹的绝对路径

委托方立场：原告 / 被告 / 其他（请填写）
程序阶段：一审 / 二审 / 再审 / 执行 / 非诉（请填写）
交付格式：先在对话中给我提纲和待确认事项，确认后再生成 Word 初稿。

请先读取案件梳理报告及相关合同、付款凭证、沟通记录和其他证据。列出材料支持的事实、各方不同说法、诉讼请求所需但材料未明确的内容。不要自行补造身份信息、金额、日期、请求或法律依据；未核实内容标注“待确认”或“待检索”。
```

### 从散乱材料开始

如果材料尚未整理，先提供原始材料文件夹并完成材料整理；确认归档和初步案件报告后，再按上面的模板启动起草。也可以在同一请求中说明最终目标，但应先确认分类预览和关键案件信息，再进入文书起草。

### 其他常见文书

将模板中的“民事起诉状”替换为需要的文书，并补充适用场景：

```text
请起草【答辩状 / 上诉状 / 代理词 / 律师函 / 法律意见书】。
我方身份及立场：【填写】
程序阶段或发送对象：【填写】
希望解决的问题：【填写】
```

不同文书的结构不同。说明目标和立场即可，不必预先告诉 Agent 使用何种论证结构；法律文书应由律师审核后使用。

## 合同或协议起草

合同起草与审查分属不同 Skill。新起草或实质改写合同使用 `@lawyerbuddy-contract-draft`；检查已有合同风险使用 `@lawyerbuddy-contract-review`。

```text
@lawyerbuddy-contract-draft

请根据以下交易条件起草一份【合同/协议类型】初稿。
我方身份及立场：【填写】
已谈妥事项：【填写或附相关材料路径】
交付：先列出模板选择、主要待确认事项和条款提纲；确认后生成可编辑 Word 初稿。
不要把模板示例、未知事实或建议条款写成双方已达成的约定。
```

## 先确认，再成稿

案件材料不足时，建议先让 Agent 输出以下内容，不要直接要求它填满正式文书：

- 文书提纲和拟采用的请求或答辩事项；
- 每项主要事实对应的材料名称；
- 缺失或冲突的信息，例如主体身份、日期、金额、履行情况；
- 需要律师确认的法律依据和需要进一步检索的内容。

确认或补充后，再要求生成完整初稿。对金额、日期、主体、请求范围等关键内容有疑问时，可以继续专项核对，不必重新整理全部材料。

## 常用指令

```text
请先给我文书提纲和待确认事项，暂不生成全文。
请只核对付款金额和付款日期，并列出对应材料。
请把每项事实对应的证据名称标在文书草稿旁，无法对应的标为待确认。
请检查这份草稿中的当事人信息、金额、日期和法律依据，不要改动没有材料支持的事实。
```

不要在提示词中输入不必要的身份证号、银行卡号等敏感信息；如确有必要，应通过符合所在机构和平台要求的安全方式处理。
