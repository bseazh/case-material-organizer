# 合同条款检查表

| 检查对象 | 写清什么 | 避免什么 |
|---|---|---|
| 主体与授权 | 自然人姓名及身份信息；组织全称、代码、住所及签约代表；实际收付款主体 | 公司简称、主体错位、捏造授权 |
| 标的与范围 | 可识别的房屋/金额/岗位/财产；数量质量、用途、边界和附件 | 空泛写“相关服务”“全部财产”而无法识别 |
| 价款支付 | 币种、金额及大写、账户户名、付款日或触发条件、分期、发票税费 | 默认已付款、默认最高利率、虚构账户 |
| 履行与验收 | 谁在何地何时完成什么，交付物、验收标准和期限、异议及补救 | 单靠“及时”“合理期限”掩盖已可确定的节点 |
| 承诺保证 | 权属、瑕疵、处分权、信息披露与配合义务 | 把未核实事实写成已经查明 |
| 违约和解除 | 违约情形、催告补救、解除通知、返还结算、损失与合理维权费用 | 无依据高额惩罚、重复赔偿、默认单方免责 |
| 争议处理 | 依事项和法域明确合法程序、机构/法院及连接点 | 商事仲裁与劳动仲裁混用；身份争议任意仲裁 |
| 通知送达 | 地址、方式、变更义务、到达及证明机制 | 合同约定当然代替法院送达程序 |
| 生效签署 | 成立、生效条件、签署栏、份数、必要登记和对外效力 | 签字等于过户、签协议等于离婚 |
| 附件 | 名称、版本、实际是否存在、优先顺序、冲突处理 | 引用不存在的保证函、保险摘要或财产清单 |

上述是起草检查项，不是所有合同缺一项即无效。条款适用需结合合同类型。

## 最终一致性

主体角色在正文、收款账户、担保和签署页一致；所有选项只保留适用内容；期限、金额大小写、比例和分期加总一致；解除后的返还、赔偿、担保及通知安排无冲突；编号及交叉引用正确；模板中的固定示例数据和“请填充”已替换或转为显式待确认。用户已谈妥的条件与建议修改分别标识，不能把建议变成既成合意。

可见占位符允许交付草稿，但重要条款未定、附件缺失、境外规则未核验时，说明具体缺口，不标记为可签署终稿。
