# 起诉状模板路由

选择顺序：文书类型与法域 → 法律关系 → 原被告身份与具体请求 → 用户格式偏好及受理法院实际要求 → 模板版本。文件名中的“最高院2025版”仅为用户原文件标签，未逐格认证与官方现行下载完全一致；有官方格式要求时需查证并比对最新版。

| ID | 适用条件 | 格式与选择 |
|---|---|---|
| Q01 | 已确认属于民间借贷，债权人起诉追偿 | 要素式；未指定格式时可优先选 |
| Q02 | 已确认房屋租赁关系，出租人或承租人诉请 | 要素式；按原告身份填对应项 |
| Q03 | 通过诉讼请求解除现存婚姻并处理相关事项 | 要素式；不得用于离婚后单独财产纠纷 |
| Q04 | 确认为租赁押金返还，被告作为出租/转租主体承担义务，且选择叙述式 | 非要素式中介押金示例；仅借用结构 |
| Q05 | 民间借贷且用户选择叙述式，或确有充分展开需要 | 非要素式；补齐实际主体类型、证据和担保 |
| Q06 | 离婚且选择叙述式，或需展开复杂争议 | 非要素式详细示例；删去全部未经用户提供的事实 |

没有格式偏好且事实适配 Q01–Q03 时可自主优先要素式；复杂案件也可以扩容或附页，不因复杂就强行改格式。用户明确选择叙述式应尊重。2025 年示范文本推广不等于强制使用，67 类也不是本库模板数量或永久固定清单。

## 必须询问的歧义

- “中介不退钱”：先问钱是租赁押金还是中介服务费，中介以什么身份签约/收款。不能仅凭收款人就确定被告和案由。
- “朋友拿钱做生意”：先问是承诺返本付息的借款、共同投资还是其他安排。
- “离婚分财产”：先问婚姻是否已解除，以及要起诉还是双方签协议。协议归合同 skill；已离婚财产争议无专用现成模板。
- 没有对应模板：明确现有库不覆盖，询问是否采用查得的官方对应模板或定制非要素式；不能冒充已有官方模板。
- 用户指定法院/格式与合同仲裁条款、法域或程序要求冲突：指出具体冲突，确认事实和办理路径，不能直接承诺该法院管辖。

## 原始模板的定点修正

- Q04 标题“起诉书”改为“民事起诉状”；误工、交通费必须有事实和法律依据；租赁设施维修责任、损坏原因与举证责任不能机械等同。不预置“被告必须证明所有事项”。
- Q05 “分三次还款”等是示例；用实际逐笔台账替换，不继承默认主体为法人。
- Q06 出轨、家暴、疾病、生育风险、学历、收入、海外亲属均是示例，不是本案事实；不愿生育不直接标为独立法定离婚事由；子女利益判断不等于学历排名。
- Q01–Q03 未知勾选保持待确认；借贷模板法人被告身份栏不够时可在对应栏补充信息或附页，不删除原始要素。
